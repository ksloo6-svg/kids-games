# 젤리 런 — 작업 인수인계

## 기본 정보
- 게임 주소: https://ksloo6-svg.github.io/kids-games/jelly/
- 파일: `jelly/index.html` + `jelly/three.module.min.js`(Three.js r160, 계단 레이스와 같은 파일). 외부는 구글 폰트만. 아이콘·manifest 포함(홈 화면 이름 "젤리런").
- 참고 원작: Jelly Run 2048 (AI Games FZ). 규칙은 원작과 비슷하게, 이름·그림은 새로 만듦. 속도는 원작보다 느리게.
- `<script type="module">`이라 로컬 서버로 테스트. 자동 테스트용 `window.jellyDebug()`.

## 게임 규칙
- 3D 무지개 길. 젤리는 저절로 앞으로 달림(속도 6, 결승 뒤 9.5).
- 화면을 톡 치면 젤리가 양옆(x=±1.6)으로 쪼개지고, 다시 톡 치면 가운데로 붙음(토글, PC는 스페이스).
- 젤리 한 줄 = 숫자 큐브 사슬(큰 것이 앞). 같은 숫자는 자동 합체(2048 방식). 쪼개기/붙이기로 합계는 바뀌지 않음: 큐브 하나면 반씩, 여럿이면 번갈아 나눔.
- 길 위 숫자 큐브는 닿으면 무엇이든 먹고 사슬에 붙음 → 같은 숫자면 "합체!".
- 가운데 막대 = 쪼개서 피함(초록 ←→ 표지), 양쪽 막대 = 붙여서 피함(파랑 →← 표지). 모양이 틀리면 화면에 "톡!" 손가락 힌트.
- 막대에 부딪히면 "앗!" 잠깐 느려지고 가장 작은 큐브를 잃음(하나뿐이면 반으로, 최소 2·4는 보장). 처음부터 다시 하기 없음.
- 결승선 뒤 숫자 벽 10개(4, 8, … 2048, 바닥에 x1~x10). 합계가 벽 숫자 이상이면 부수고 계속, 아니면 멈춤.
- 결승까지 오면 항상 다음 레벨이 열림. 첫 화면 ◀ ▶로 지난 레벨을 다시 할 수 있음.
- 같은 레벨은 항상 같은 코스(시드 고정). 레벨이 오를수록 길이·막대 비율·큐브 숫자가 커짐.

## 코인·업그레이드
- 보상: (10 + 레벨×2) × (부순 벽 수 + 1).
- 시작 젤리 업그레이드: 4 → 8 → … → 128, 비용 40, 80, 160 …
- 저장: localStorage `jelly-level`(열린 최고 레벨), `jelly-cur`, `jelly-coins`, `jelly-start`(시작 젤리 2의 지수).
