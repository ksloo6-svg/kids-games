# 구멍 먹보 — 작업 인수인계

## 기본 정보
- 게임 주소: https://ksloo6-svg.github.io/kids-games/hole/
- 파일: `hole/index.html` + `hole/three.module.min.js`(Three.js r160, 계단 레이스·젤리 런과 같은 파일). 외부는 구글 폰트만. 아이콘·manifest 포함(홈 화면 이름 "구멍먹보").
- 참고 원작: Hole.io (Voodoo). 규칙은 원작과 비슷하게, 이름·그림은 새로 만듦. 속도는 원작보다 느리게.
- `<script type="module">`이라 로컬 서버로 테스트. 자동 테스트용 `window.holeDebug()`, `holeSim(초)`(화면 없이 시간 돌리기), `holeTime(초)`, `window.holeAuto=true`(내 구멍 자동 조종).

## 게임 규칙
- 3D 도시(도로 격자 + 공원·주택·상가·빌딩 블록). 화면 아무 데나 손가락을 대고 끌면 구멍이 움직임(떠다니는 조이스틱, PC는 방향키/WASD).
- 물건마다 크기·점수: 사람·콘·소화전·쓰레기통 1, 벤치·덤불·가로등 2, 나무 4, 자동차 6, 가게 10, 버스 14, 집 25, 빌딩 50, 큰 빌딩 100.
- 물건 크기가 구멍 반지름의 90%보다 작고 중심이 구멍 안에 들어오면 빠짐. 너무 크면 흔들리기만 함.
- 점수가 차면 구멍 둘레 노란 링이 한 바퀴 돌고 한 단계 커짐(반지름 0.5×1.17^단계, 최대 14단계).
- 그 단계에 필요한 점수: 6×1.45^단계.
- 이동 속도 2.8+반지름×0.8 (원작보다 느림). 큰 구멍일수록 카메라가 멀어짐.
- 구멍끼리는 먹지 않음(아이가 당하는 방해 없음). 겹치면 서로 밀려남.
- 한 판 2분. 친구 레벨: 상대 3~5개(랜덤 이름·색), 끝났을 때 점수 순위. 상대는 앞서가면 느려짐(따라잡기 쉽게).
- 3, 6, 9… 레벨은 혼자 레벨: 도시의 목표 %(18+레벨×1.5, 최대 50)를 먹으면 바로 성공.
- 끝까지 하면 순위와 상관없이 다음 레벨이 열림. 첫 화면 ◀ ▶로 지난 레벨을 다시 할 수 있음. 같은 레벨은 같은 도시(시드 고정).

## 코인·꾸미기
- 보상: 친구 레벨은 등수별 60/40/28/20/14/10 + 레벨×2, 혼자 레벨은 20+%×0.6(+성공 30) + 레벨×2.
- 구멍 꾸미기: 괴물 입(기본, 앱 아이콘 모양)·기본 무료, 고양이 100, 꽃 150, 무지개 200, 별 300. 누르면 바로 적용.
- 저장: localStorage `hole-level`(열린 최고 레벨), `hole-cur`, `hole-coins`, `hole-skins`(산 꾸미기), `hole-skin`(쓰는 꾸미기).

## 구현 메모
- 구멍은 스텐실로 그림: 보이지 않는 원판이 스텐실에 1을 쓰고, 땅은 그 자리를 건너뜀 → 아래 어두운 원통 속으로 물건이 떨어지는 게 보임.
- 도시 물건은 부품을 하나의 지오메트리로 합쳐(정점 색) 물건 하나당 그리기 1번.
